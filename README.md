# Planner

Offline Android app (Kotlin, Compose, Material 3, Room, DataStore). More sections will be added over time;
the first one is **Study**: weekly timetable (hours down the side, days across the top, classes as cards),
courses with a 54-colour palette plus a custom colour mixer, exams, assignments and study sessions.
Arabic (RTL) and English (LTR), light and dark themes. No internet permission, all data stays on the device.

Push to GitHub: the workflow builds the APK and runs the instrumented tests.
